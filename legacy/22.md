# NUT-22 (legacy): DLEQ proofs on blind authentication tokens

`legacy`

> Blind authentication tokens on [pre-v3 keysets](../02.md#keyset-id-v3) carry a DLEQ proof. The current specification is [NUT-22](../22.md).

---

On pre-v3 keysets, the mint MUST return a DLEQ proof ([NUT-12](12.md)) for every blind signature in `PostAuthBlindMintResponse`, and the wallet stores it on the `AuthProof`:

```json
{
  "id": <hex_str>,
  "secret": <str>,
  "C": <hex_str>,
  "dleq": {
    "e": <str>,
    "s": <str>,
    "r": <str>
  }
}
```

Wallets MUST verify the `dleq` of every pre-v3 `AuthProof`, so the mint cannot tag a user by signing with an unpublished key. A pre-v3 `AuthProof` sent to another user of the mint MUST include its `dleq` so that the receiving user can validate it.

> [!CAUTION]
>
> To protect the privacy of the wallet, the BAT MUST NOT contain the `dleq` proof when it is sent to the mint in the request header.
